# PopGenomic_Parameter_Visualizations
Scripts used to visualize the population genomic parameter estimates. Used in Global Characterization of Diversity and Selective Pressures in Five Plasmodium falciparum Loci Identified by Whole-Genome Sieve Analysis as Putative Antigens

This contains a number of R scripts used to visualize the reference based reconstructions from MalariaGens Pf7 data. These scripts contain R code for visualizing 
- nucleotide diversity
- haplotype diversity
- nonsynonymous/synonymous nucleotide diversity
- regression modeling of nucleotide diversity by API
- Tajima's D
- McDonald-Kreitman Neutrality Index
- Statistical testing between API groups
- API calculations
